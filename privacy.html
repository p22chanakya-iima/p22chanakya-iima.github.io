Privacy

This is a static personal portfolio site. It doesn't run any third-party analytics or advertising scripts, doesn't set tracking cookies, and doesn't collect or store any personal data about visitors.

The only browser storage used is a single localStorage key on this device, to remember your light/dark theme preference. It never leaves your browser and isn't read by anything on this site or elsewhere.

The contact email and contact page are for reaching me directly — anything you send there goes to my inbox, not a mailing list or third party.

This site is hosted on GitHub Pages, which may log standard web server access data (e.g. IP address, request timestamps) per GitHub's own privacy statement — that's GitHub's infrastructure logging, not anything this site adds.
